# BookForgeAI — Book Pipeline

01 Discover — raw idea to brief.
02 Research — evidence and source library.
03 Map — knowledge/story map.
04 Visual Canon — recurring characters/items/locations.
05 Architect — overall structure.
06 Design — voice, tone, pacing, visual language.
07 Outline — chapter/section plan.
08 Author — chapter drafts.
09 Illustrate — scene composer → image director → GPT-Image-2 → visual QA.
10 Criticise — independent critics.
11 Diagnose — actionable revision tasks.
12 Rewrite — apply fixes.
13 Edit — substantive, line and copy editing.
14 Continuity — cross-book consistency.
15 Layout — structured page model.
16 Proof — rendered PDF QA.
17 Publish — approval + $100 payment.
18 Deliver — immutable edition + PDF.
