# BookForgeAI — Roadmap

## Phase 1 — MVP

Project dashboard, idea/brief, map, Visual Canon, architecture, outline, authoring, illustration, critique/revision, PDF, $100 publishing payment.

## Phase 2

Better visual continuity, cover generation, more templates, advanced editing, version history, EPUB, DOCX, citations.

## Phase 3

Audiobooks, translation, collaboration, publisher accounts, print-ready exports and distribution integrations.

## Phase 4

Multi-book series continuity, shared universes, reusable character/world libraries and publisher automation.
